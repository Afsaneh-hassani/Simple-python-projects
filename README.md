# Python Projects Collection

A collection of Python projects covering core programming concepts — from date handling and object-oriented design to database querying and sorting algorithms.

---

## Projects

### 📅 Project 1 — Age Calculator
Calculates a person's age from their date of birth (format: `yyyy/mm/dd`).
Includes input validation — if the date is invalid (e.g. month > 12 or day > 31), the program returns `WRONG`.

**Concepts:** `datetime` library · input validation · error handling

---

### ⚽ Project 2 — Football Team Generator
Defines a `Footballer` class that inherits from a `Human` base class.
Creates footballer objects, assigns player names, then randomly divides them into two teams (A and B) and prints each player with their assigned team.

**Concepts:** Object-Oriented Programming (OOP) · inheritance · `random` module

---

### 🗄️ Project 3 — Employee Database Sorter
Reads employee data (name, height, weight) from a database and prints employees sorted by height.
If two employees share the same height, the one with lower weight is listed first.

**Concepts:** Database reading · sorting with multiple conditions · `lambda` functions

---

### 📅 dateage.py
A standalone script for age calculation from a given date — an earlier exploration of the `datetime` library.

---

## Tech Stack

- **Language:** Python 3
- **Libraries:** `datetime` · `random`
- **Concepts covered:** OOP · inheritance · input validation · sorting · database interaction
